为什么不是一个很大的模型？

手机 RAM 和算力有限。GoPlay 把任务拆开：轻量模型或规则做状态过滤，推理级小模型只做策略选择，规则引擎做输出校验和动作序列化。下载的是与设备档位匹配的一个策略模型，不是把所有模型塞进安装包。

分层记忆

记忆

全局只存跨游戏偏好；具体游戏状态留在各自实例。工作记忆、摘要层、可检索事实会在预算内自动压缩。

跨游戏偏好

进入决策前经过实例适配层，冲突时游戏规则优先。

各游戏记忆

固定在存储预算内，优先保留「必须记住」的事件。
